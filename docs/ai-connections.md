# AI 连接

顶部「AI 连接」显示当前 AI 服务是否连接，点击即可查看连接说明或切换服务。

## Codex 账号

1. 在这台电脑安装 Codex，使用自己的 ChatGPT 账号登录。
2. 在 iSpine 打开「AI 连接」，选择「Codex 账号」。已登录的账号会自动识别，无需 API Key。
3. 未登录时可以点击「开始 Codex 登录」，再打开返回的官方登录页面，在浏览器完成登录。也可以在 Codex 中登录后刷新连接。
4. 点击「使用 Codex 账号」。随后在角色编辑器中进入「AI 创作」，生成形象或模板部件。

登录与令牌续期由 Codex App Server 管理，iSpine 不读取或复制 Codex 的认证文件。使用现有已登录账号只需选择连接方式；切换 AI 服务不会退出 Codex。

「我的资源 → 新建角色」还提供独立骨架流程：参考图可先通过当前选定的图片服务生成 Q 版透明立绘，确认形象后再分析结构。结构识别、原图坐标规划和动作规划使用 Codex 账号的结构化输出，部件透明补绘使用当前选定的图片服务。坐标规划提交固定立绘、像素网格和部件几何，返回轮廓坐标；可见像素的分配与合成由本地程序完成。形象、结构、补绘、坐标与动作各自保存候选，需用户应用后才修改草稿；取消或重启中断不会自动重新提交。原始参考文件、最终形象及生成来源分别保留。API Key 图片服务目前不承担结构、坐标和动作规划，界面会分别显示两者使用的服务。操作见 [新骨架与动作](rig-authoring.md)。

官方资料：[安装与登录](https://learn.chatgpt.com/docs/codex)、[App Server 登录接口](https://learn.chatgpt.com/docs/app-server)。

动作画面重制也使用当前选定的图片服务，先生成同尺度的动作关键画面，再由 Codex 分析关节、可见部件轮廓与遮挡。原画、坐标分别保存候选，需要逐张审阅并明确应用。图片最多 3 张并发；坐标分析可以复用已分析的同一张基准图。失败重试只处理缺失画面，不自动切换服务。

## OpenAI API Key

1. 在自己的 [OpenAI API 项目](https://platform.openai.com/api-keys) 创建 API Key，并确认项目具备所选生图模型的访问权限。
2. 选择「OpenAI API」，填写 Key 并选择模型。
3. 本机后台支持勾选「在本机安全保存 API Key」。未勾选或当前环境无法使用系统保护时，Key 仅在本次运行中保留。
4. 点击「保存并验证连接」。验证通过后成为当前默认服务；进入角色的「AI 创作」继续生成。

连接验证读取模型信息，不生成图片。验证通过表示密钥可访问所选模型，实际生图权限、用量限制与图片结果仍会在生成请求时检查。API 用量由用户自己的 API 账户结算；只有点击生成或继续生成才会提交图片请求。默认模型与可选项来自接入模块的模型列表。

macOS 本机后台以钥匙串保护的主密钥执行 AES-256-GCM 加密，配置文件沿用用户数据目录的 `generation/jobs/.connection/connection.json`。浏览器不接收已保存的 Key。没有系统密钥保护时使用内存保存，不以明文文件代替。配置接口只返回是否已配置/保存，不返回密钥。Key 不进入工程、生成记录、提示词或导出 ZIP。

启动后台、浏览资源、查看连接设置和使用默认 Codex 账号均不会读取钥匙串。已保存的 API Key 在重启后保持锁定；点击「保存并验证连接」或实际使用该 API 生成时才按需解锁。验证失败、解锁取消或加密失败不会覆盖原密文。旧 Electron 密文也会保留，必要时在新后台重新验证连接。macOS 可能在显式保存或解锁时要求系统确认。

「移除已配置的 Key」只清除此应用的 API Key；仍需重新连接该服务后才可生成。生成进行中不能更改服务、模型或密钥。服务切换不会自动重做旧任务；失败或中断任务的继续生成保留原服务、模型、描述和部件映射。生成失败不会自动使用另一个服务。

官方资料：[图片生成与参考图编辑](https://developers.openai.com/api/docs/guides/image-generation)。

## Sub2API

1. 选择「Sub2API」，填写自己的服务地址，例如 `http://127.0.0.1:18080/v1`。远程地址必须使用 HTTPS；本机 HTTP 可以通过 SSH 加密隧道连接远程网关。
2. 在 Sub2API 后台授权上游账号、配置模型分组，并创建该分组的网关密钥。这里填写的是网关密钥，账号登录与续期由 Sub2API 管理。
3. GPT Image 选择「OpenAI Images」，Gemini 图片模型选择「Gemini 原生图片接口」。模型名称可自行填写，验证会检查网关实际返回的模型目录；建议名称不保证所有账号均有权限。
4. 点击「保存并验证连接」。实际生成继续进入同一套形象、部件候选、校准、动画检查与导出流程。

验证只请求模型目录，不调用生图。OpenAI Images 使用 `/v1/images/generations` 与多图 multipart `/v1/images/edits`；Gemini 使用 `/v1beta/models/{model}:generateContent`，参考图以内联图片提交。若使用 Antigravity 专用路由，可填写包含 `/antigravity/v1beta` 的地址。

网关返回的 Base64、图片 data URL 和同源图片 URL 会转为本地 PNG 候选；图片下载不携带网关密钥，不跟随重定向。外部存储图片 URL 需在网关改为 Base64 返回。JPEG/WebP 可转换为同尺寸 PNG，真实透明度仍由任务校验，转换不代表透明背景生成成功。

Sub2API 与其他 API 服务共用系统加密、按需解锁和会话存储规则。网关地址、图片接口和模型会固定到任务记录；改动连接后不能把旧任务交给另一个地址。切换地址或接口需重新输入网关密钥，失败验证保留原连接和密文。并行取消会中止本地全部请求；上游是否立即停止计算取决于网关和模型的取消能力。结构、坐标与动作规划仍由现有 Codex 结构化分析服务处理。

部署和连接维护见 [Sub2API 网关](sub2api.md)。上游说明：[Sub2API](https://github.com/Wei-Shaw/sub2api)。

## 新增其他 AI 服务

`server/providers/` 中每个服务提供一个独立适配器，在 `AIConnections` 的注册列表中加入适配器后，连接面板读取同一份服务与模型目录。API Key 类型可继续使用已有输入、模型选择、加密保存和验证表单；其他认证方式需要增加对应的登录表单。

适配器契约：

| 字段或方法 | 内容 |
| --- | --- |
| `id` / `label` | 稳定服务 ID 与用户可见名称 |
| `auth` / `models` / `links` | 认证方式、可用模型列表、设置文档与密钥创建链接 |
| `status(settings)` | 验证连接并返回 `connected`、`message`，不生成图片 |
| `generate(settings, options)` | 接收提示词、参考图文件路径与取消信号；返回 `result`（PNG Base64）和 `model` |
| `login()` | 账号认证方式的可选登录入口 |

`server/ai-connections.mjs` 管理连接选择、受保护的凭据和公开配置；`server/generation-service.mjs` 管理独立任务、并行上限、取消、候选、透明 PNG 检查及部件映射。新适配器仍使用现有校准、预览与导出流程。当前界面提供 Codex、OpenAI 和 Sub2API 三种服务。可配置网关适配器通过 `normalizeSettings` 校验并保存服务地址及图片接口，通过 `allowCustomModel` 提供可填写的模型名称。

开发验证覆盖服务注册、模型与凭据校验、密钥保护及重启恢复、参考图上传、透明 PNG、完整部件应用与导出、并行取消、任务恢复、同源边界与失败处理。真实 Codex 连接已经检查；真实 API 生图需要用户自己的有效 Key 和模型权限，测试不声称已完成该项外部验证。
