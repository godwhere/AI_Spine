# 本机网页工作台

iSpine 的日常入口是 [本机工作台](http://127.0.0.1:4175)。界面在浏览器运行，资源、回收站、骨架草稿、自建模板和正式生成记录由一个本机后台保存。Chrome 和内置浏览器读取同一份数据；各自的选中项、页面和缩放状态独立。

## 启动与使用

当前 Mac 的 `local.ispine.workbench` 登录启动项自动运行后台。双击项目中的 `启动工作台.command` 可打开页面；原 `启动桌面工作台.command` 保留为兼容入口，也会打开网页。关闭浏览器不会停止后台或删除工程。电脑关机后数据仍保留，再次登录会恢复服务。

运行环境为 Node.js 24，界面由 `pnpm build` 构建到 `dist/client`。其他本机环境可通过 `pnpm workbench` 启动。后台只监听回环地址，不开放公网；同一台电脑使用无需域名或额外服务器。现有美国服务器仍只承担配置的 AI 网关。跨设备或异地访问需要另外设计身份验证、HTTPS 和文件权限，不属于当前本机运行范围。

正式地址固定为 `http://127.0.0.1:4175`。旧的 4173、4180 地址在可用时由同一进程代理到正式服务；运行中的 Vite 开发页也将正式数据和生成 API 代理到这个后台。独立的开发预览任务仍使用各自端口的历史目录，不让一个实例中断另一个实例的任务。

## 数据与恢复

沿用 `~/Library/Application Support/AI Spine`：

| 内容 | 位置 |
| --- | --- |
| 资源、回收站、删除标记、草稿、自建模板 | `workspace/workspace.sqlite` |
| 生成输入、候选和任务记录 | `generation/jobs` |
| 加密连接配置 | `generation/jobs/.connection/connection.json` |
| 原桌面快照与导入冲突备份 | `migration` |
| 后台运行日志 | `logs` |

数据库按原项目、草稿、模板的名称分区，保持生命周期独立。资源列表只返回摘要；选中角色时读取其原始文件、替换图片和校准信息。回收站恢复、永久删除确认、ID 删除标记、未修改的临时模板不保存等规则继续保留。

旧浏览器数据库在第一次打开对应来源地址时自动迁入。迁移完成标记属于浏览器，资源本身属于本机后台；清理浏览器缓存不会删除后台工程。原 IndexedDB 名称与内容保留为迁移来源。相同记录不重复导入；同 ID 的不同内容以独立迁入版本保存，不覆盖已有内容。已经移入回收站或永久删除的项目不会因旧浏览器重新迁移而复活。服务不可用时明确报告保存失败，不自动改存到另一份浏览器数据库。

资源与草稿使用版本检查，避免两个浏览器编辑时静默覆盖较新的版本。资源库定期检查数据版本，其他入口保存后会刷新列表；正在编辑的内容不会被后台更新直接替换。

旧桌面完整备份保存在 `~/Library/Application Support/iSpine Backups/20261020-211941-before-web`。迁移核对覆盖 20 条原始记录，包括 4 个资源、1 个回收站项目、7 个 ID 删除标记、3 份草稿及 1 个自建模板。随后浏览器迁入了原本独立的花杖少女制作稿，合并库中为 5 个正常资源。既有 53 条开发/预览历史记录另行复制到正式生成历史；原目录保留。

迁移与导出备份独立于回收站操作。携带工程到其他电脑时仍使用可编辑 ZIP；备份整个工作台时应先停止后台，再复制用户数据目录，或使用 SQLite 的一致性备份机制，不能只复制运行中的数据库主文件而忽略 WAL。

## AI 连接与密钥

继续明确选择 Codex、OpenAI 或 Sub2API，失败不切换服务。macOS 本机后台使用钥匙串保护的主密钥加密保存 API Key。启动、查看连接和浏览资源不读取钥匙串；只有显式验证、保存或实际 API 生成才加解密。缺少系统保护时仅保留本次进程内的 Key，不写明文文件。旧桌面密文在无法解锁时保留。

本次迁移没有发起图片请求或自动续做失败任务。Sub2API 的并发配置、网页生图上游 503/500 和图片质量验收均是独立事项。

## 验证

`pnpm test:workspace` 检查独立客户端、重启持久化、原图字节、版本冲突、回收站、迁移幂等性、冲突保留、请求来源限制和延迟密钥解锁。迁移记录位于 `outputs/desktop/evidence/shared-workspace-migration.json` 与 `shared-workspace-job-migration.json`。其他资源、骨架、动画和导出规则仍由原有测试覆盖。
