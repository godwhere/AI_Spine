# 模板动作部件变体

在普通模板资源中，可让同一部件在指定动作使用另一张图片，例如受击和战败时切换痛苦头部，其他动作使用默认头部。

1. 在「AI 创作 → 模板部件」生成并检查单个部件候选。
2. 将「候选应用范围」切换为「指定动作」，填写变体名称并选择动作。
3. 应用这一张候选，在「调整细节」校准，再逐个预览动作。
4. 导出运行时包、可编辑工程或 Unity 包。变体、默认恢复与来源数据随包保存。

当前支持 JSON 骨架中明确对应到一个插槽的刚性区域附件。二进制骨架、网格附件、跨插槽复用以及原动作已存在不兼容附件切换时会明确拒绝，避免覆盖原绑定。多个变体不能同时占用同一动作的同一插槽。

新增变体保留原部件的附件尺寸、偏移、裁切和 Atlas 旋转，使用独立贴图页；不会改变骨骼、其他运动通道或原有透明渐隐。未选中的动作在起始时明确恢复默认附件。原生候选与生成任务映射独立保存；校准不修改原生图片。

同名变体再次应用会更新同一变体；同一原生图片仅修改适用动作时保留已有校准。来源指纹必须匹配当前资源或清单内冻结的原模板。普通「全部动作」应用仍严格要求当前资源指纹。新增、更新、校准都可以撤销与重做，历史同时恢复骨架资源、贴图和选择。

原模板对照使用冻结的原骨架和 Atlas，不跟随指定动作切换变体。运行时包的原模板对照使用导入时的烘焙贴图；可编辑工程另保留替换图与校准记录。
