## 验收边界

- 本轮完成 Codex 原生形象/部件生成、导入、替换/校准、真实动画、保存、导出和重新导入；没有积分或独立账户系统。
- 仅支持 4.3.x，不提供 `.spine` 工程写入、跨版本转换、自由网格、Warp、钢笔分割或跨工程多角色皮肤合并。已有皮肤完整保留并可预览。
- 替换图片保留上传的背景，不自动抠图。透明 PNG 最适合部件替换。
- 原 Atlas 区域和原 mesh 是输出范围；大幅改变轮廓可能需要后续网格编辑，不应只用缩放掩盖裁切。
- AI 通过本机 Codex 执行；本机服务须保持运行。静态部署不提供此本机能力。形象是风格参考，只有选中的纹理区域会被替换；其他姿势引用的独立区域需另选后生成。
