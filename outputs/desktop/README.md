# Historical iSpine desktop artifacts

Daily use opens [the shared local browser workbench](http://127.0.0.1:4175). See [current workbench storage and launch](../../docs/workbench.md). The desktop delivery notes below are historical; App data has been backed up and migrated, and the former App launch shortcut now opens the browser.

Open `iSpine.app`, or double-click `../../启动桌面工作台.command` from the project. This is the local macOS Apple Silicon build (version 0.1.0). It starts its own resource and Codex service; a separate Node.js installation or browser server is not required by the packaged app.

“我的资源” lists the projects saved in this app's local profile. Single-click to preview, then use “编辑与校准” or double-click to edit. First launch can seed the complete six-part Starberry example. Imported and edited projects remain available across app updates.

The light explorer offers top navigation, searchable rows, animation preview and an inspector. The template library contains 38 built-in templates: 37 characters and one animated effect. Type/category controls sit above the library. Template display offers the unchanged one-column list and three-column pictures in a compact left pane, with a large central animation and separate right inspector or a dedicated mobile preview. Resources can be saved as independent templates under “我创建的”, preserving baked replacements/calibration; saving again updates the same template. Export also offers Unity resources with `.atlas.txt` / `.skel.bytes` naming and import instructions.

Select a resource and choose “删除资源” to confirm moving it into “回收站”. “恢复资源” returns its saved images, calibration, and appearance reference. Trash supports separately confirmed permanent removal and emptying. Unchanged new template drafts are discarded when leaving; edits, authored prompts, explicit saving or export keep them. Existing project storage and editable backups remain compatible.

The app stores projects separately from browser profiles under `~/Library/Application Support/AI Spine`. Other browser projects can be transferred by exporting and importing an editable ZIP. “AI 连接” defaults to the installed, signed-in Codex account and also supports an explicitly selected OpenAI API Key. Remembered desktop keys use system encryption and stay outside project backups. Credits and billing are absent.

“我的资源 → 新建角色” can first generate a cel-shaded Q-version illustration from an identity reference, then create an independent humanoid rig: AI structure and part proposals, draggable joints, transparent image calibration, rigid or weighted meshes, vertex weights, foot/weapon constraints and motion keyframes. Candidates require explicit application. Drafts remain separate from normal resources until all independent parts and actions pass their checks. Saved resources can reopen “骨架与动作”; exports include the exact original reference, final illustration, authoring data and individual PNGs. See [rig-authoring.md](../../docs/rig-authoring.md).

Current validation passed: core 280/280, complete-Egg 9/9, production-serving 4/4 and actual-bundle desktop 9/9, plus production build and bundle signature. The in-app Codex workflow produced a 25-joint, 44-part pink mage, five facial attachment groups and seven actions. Source-coordinate registration preserves its setup silhouette and proportions. Separately, 547 artifact checks covered 1042 official-runtime samples, preserved the six other actions during attack regeneration and verified a byte-identical export/re-import/export ZIP. Official Spine Editor, Unity Editor and real external API Key generation have not been tested. Full evidence remains recorded in [desktop.md](../../docs/desktop.md) and [validation.md](../../docs/validation.md).

The final package is installed.
