# 制作产物与保留样本

此目录保存本机制作的角色原图、独立部件、可编辑工程、运行时交付包、截图与检查报告。正式资源库、草稿和生成任务保存在独立的[本机数据目录](../docs/workbench.md#数据与恢复)。

新增制作产物默认由 `.gitignore` 排除，避免把每次生成、预览和下载都加入源码仓库。已有受版本控制的交付样本继续保留；需要新增公共样本时，明确选择文件并连同来源、许可和验证说明一起纳入。

## 目录归属

| 路径 | 内容 |
| --- | --- |
| `egg-starberry/` | 完整 Starberry 角色与导出回导验收样本 |
| `panda-wukong/`、`pink-mage/` | 已保留的角色制作与交付记录 |
| `generation/`、`rig-authoring/`、`verification/` | 生成、骨架制作与导出检查样本 |
| `desktop/` | 历史桌面交付、共享工作区迁移和界面截图 |
| `pink-mage-*/`、`production-workflow/` | 当前电脑上的各版制作草稿、修正、动作与特效交付；新目录不默认入库 |
| `workbench-preview.png` | 保留的工作台预览截图 |

部分目录仅存在于制作电脑。目录名中的版本与阶段用于区分交付，不代表全部经过视觉验收。

## 保留规则

- `tests/archive-fixtures.test.mjs` 读取 Starberry 的可编辑包及历史桌面导出包；`tests/egg-character.test.mjs` 还读取完整角色与像素检查证据。这些已跟踪文件是可重复验证的输入。
- 项目首页和历史文档引用已有截图，整理源码时保留这些引用与图片。
- 原图、独立 PNG、可编辑 ZIP 和独立导出不属于可随意清理的构建缓存。忽略规则只影响新增文件是否进入版本控制，不删除现有内容。
- 常规测试与隔离预览将临时结果写到系统临时目录；可重新生成的构建写到 `dist/`，开发数据写到 `work/`。
